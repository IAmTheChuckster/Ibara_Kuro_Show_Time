# Skills

Claude skills used to make this patch. Each folder holds a `SKILL.md` (instructions for Claude, no ROM data).

| Skill | What it does |
|---|---|
| [cv1000-learn-game](cv1000-learn-game/SKILL.md) | Sets up the CV1000 MAME 0.289 test package with your ROM set, then plays and studies a game headlessly to learn how it works before any patching. |
| [ibara-show-time-build](ibara-show-time-build/SKILL.md) | Rebuilds this Show Time patch from scratch (SH-3 routines, Python and browser patchers, MiSTer MRA) from your own `ibarablk.zip`, and tests it in MAME. |

To use one, add the folder to your Claude skills (or give Claude the `SKILL.md`), then attach your own ROM set.
